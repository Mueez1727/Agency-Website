# ITechDev

Agency website for ITechDev, an independent software development studio.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Before launch

Update contact details in `src/config.ts`:

- email
- WhatsApp number
- LinkedIn, GitHub, Instagram
- optional form endpoint

Add founder photos to `public/images/mueez.jpg` and `public/images/haris.jpg`.

Replace the placeholder domain in `index.html`, `public/robots.txt`, and `public/sitemap.xml`.
